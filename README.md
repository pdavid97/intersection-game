# 교차로 신호 퍼즐

실제로 막히는 교차로의 신호, 차로, 통행 방향을 바꿔서 교통 흐름을 개선하는 웹 퍼즐 게임입니다.

- 플레이: 이 저장소의 GitHub Pages 주소
- 랭킹: 게임에서 제출한 기록은 '검증 대기'로 저장되고, 이 저장소의 GitHub Actions(`.github/workflows/verify.yml`)가 10분마다 같은 엔진(`engine.js`)으로 다시 계산해 확정한 기록만 랭킹에 보입니다.

## 파일

| 파일 | 내용 |
|---|---|
| index.html | 게임 전체(한 파일) |
| music/ | 배경 음악 |
| engine.js | 서버 검증용 엔진(게임과 같은 코드) |
| verify.mjs | 검증기: 설정 검사 + 점수 재계산 |
| .github/workflows/verify.yml | 10분마다 검증기 실행 |

검증기에는 저장소 Secrets의 `SUPABASE_SECRET_KEY`가 필요합니다. 이 값은 코드나 대화에 넣지 않습니다.

## 참고

- 공개 저장소의 예약 실행은 저장소에 60일 동안 활동이 없으면 GitHub가 자동으로 멈춥니다. Actions 탭에서 다시 켤 수 있습니다.
- 게임 코드는 원본 작업 폴더의 `src/`에서 고치고 빌드한 결과물만 여기에 올립니다.
